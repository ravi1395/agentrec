## Description

Move `diff` and `blame` interpretation into `agentrec-core::view`, leaving the CLI adapters as pure
renderers over typed values. This is the largest task in the phase and contains its most delicate
logic (`blame_line`'s exact-line-text heuristic).

## Location

**Files:** `agentrec-core/src/view.rs` (edit — add types + two methods), `cli/src/readcmds.rs`
(edit — `diff`/`blame` become render-only), `cli/tests/integration.rs` (edit — new assertions).

## Interface contract (produced here; consumed by P4b-5 and P5)

```rust
RepositoryView::diff(q: &DiffQuery)   -> Result<DiffResult, DiffError>
RepositoryView::blame(q: &BlameQuery) -> Result<BlameResult, BlameError>

pub struct DiffQuery  { pub turn: String, pub paths: Option<Vec<String>>,
                        pub limit: Option<usize>, pub after: Option<Cursor> }
pub struct BlameQuery { pub path: String, pub line: Option<usize> }

pub struct DiffResult {
    pub turn_id: String,      // FULL id — `fmt::short_id` truncation stays adapter-side
    pub tool: Option<String>,
    pub total_files: usize,   // the turn's own count, NOT files.items.len()
    pub files: Page<FileDiff>,
}
```

**`FileDiff` field-level definition (R23 — this task owns it).** Derived by reading every arm of
`readcmds::print_entry`; each arm becomes a pre-resolved state so the renderer needs no store:

```rust
pub struct FileDiff { pub path: String, pub state: FileDiffState }

pub enum FileDiffState {
    Withheld,                                        // secret-pattern file
    Skipped { reason: Option<String> },              // raw reason; fmt::skip_reason_text is adapter-side
    Unresolvable { corrupt: bool },                  // false = Missing, true = Corrupt (hash mismatch)
    Binary { before_len: usize, after_len: usize },
    BaselineUnknown { after: String },               // first seen mid-session; renders new content only
    Text { before: String, after: String, op: String, after_synthesized: bool },
}
```

Arm order is load-bearing and must match `print_entry` exactly: withheld → skipped → before-blob
error → after-blob error → binary → `baseline_unknown && op == "modify" && before.is_none()` →
(after_synthesized notice, then falls through) → op-dispatched unified diff. Note `BaselineUnknown`
returns **before** the `after_synthesized` check, so `after_synthesized` belongs only on `Text`.

**`BlameResult` field-level definition (R23).** Derived by reading `blame_file` and `blame_line` in
full — every branch that reaches a `println!`:

```rust
pub enum BlameResult {
    // file-level
    NoTurnRecordingGap,                                     // "attribution stale — recording gap"
    NoTurnTouches,                                          // "no recorded turn touches <path>"
    File { turn: TurnRecord, deleted: bool, gap_stale: bool, modified: bool },
    // line-level
    LineRecordingGap,                                       // gap-stale, before any line walk
    LineDeletedOrAbsent { turn: TurnRecord, deleted: bool },
    LineAttributed { turn: TurnRecord },
    LineSnapshotUnavailable,                                // "attribution unavailable — snapshot unavailable"
    LineBeforeRecording,                                    // only when history is gap-free
}
```

The attributed variants carry the whole `TurnRecord` because `readcmds::render_turn` →
`fmt::turn_detail_header` consumes it wholesale. **Two predicates stay unconflated** (CLAUDE.md):
`modified` is hash-≠-after; `gap_stale` additionally requires an uncovered interval *after* the
turn ended. Do not collapse them.

**Errors (design decision 9 — data, never prose):**

```rust
pub struct TurnRangeSummary { pub oldest_id: String, pub newest_id: String, pub count: usize }
pub enum DiffError {
    Lookup { err: LookupError, ledger: Option<TurnRangeSummary> },  // None only for NoTurns
    Cursor(CursorError),
    Io(String),
}
pub enum BlameError { FileNotFound, LineOutOfRange { lines: usize }, Io(String) }
```

**`DiffQuery`'s cursor fingerprint (R23 — highest-priority open item; AC13 is unimplementable for
`diff` without it).** `TurnQuery::fingerprint` returns only `turns:all=<bool>`. A diff cursor must
bind the turn ref and the paths filter too, or a cursor from one diff query would silently resume
inside another:

```rust
// DiffQuery::fingerprint
format!("diff:turn={};paths={}", self.turn, /* paths, joined with a separator that cannot
                                               appear in a path, or "*" when None */)
```

Pagination parameters (`limit`, `after`) are excluded, exactly as `TurnQuery::fingerprint` excludes
them — the filter must not vary page to page.

## Shared-helper resolution (blocking open question, answered here)

`print_entry`, `load_blob`, and `load_text` are shared today by `diff`, `show`, **and** `undo`.
`show` and `undo` are out of scope and keep their direct reads. Therefore: **the helpers stay in
`readcmds.rs` unchanged for `show`/`undo`, and `view::diff`/`view::blame` implement their own blob
resolution inside `agentrec-core`.** The duplication is deliberate and bounded; the alternative is
dragging out-of-scope `undo` into the seam, which the parent plan explicitly forbids.

Consequence for AC14: the file-wide `rg` count does **not** go to zero, and is not supposed to.

## Acceptance criteria

- [ ] **AC7** `view::diff` on an unknown turn ref → `DiffError::Lookup{err: Unknown, ledger: Some(..)}`;
      on a duplicated id → the collapsed turn, not `Ambiguous`. `diff_dup_turn_collapses.golden`
      passes; a distinct-turns-sharing-an-id fixture still errors ambiguous.
- [ ] **AC8** `view::diff` on a fileless turn → `DiffResult` with an empty `files` page **and**
      `turn_id`/`tool`/`total_files` still populated. CLI renders the header alone
      (`turn <id> · <tool> · 0 files`), exit 0. **New test required** — `rg '0 files' cli/tests` → 0
      today, so this case is currently pinned by nothing.
- [ ] **AC9** `view::blame` on an uncovered path → the recording-gap state with **no** attributor.
      `blame_line`'s exact-line-text heuristic is preserved verbatim, including the
      newest-unresolvable poisoning rule (a `responsible` turn is reportable only when no
      unresolvable candidate is newer). **Instrument:** the intricate arms are pinned by
      `integration.rs` tests, *not* by goldens — `golden.rs`'s residual list says so.
- [ ] **AC14** `rg 'load_log|BlobStore' cli/src/readcmds.rs` no longer matches **inside
      `readcmds::diff` or `readcmds::blame`**. State the new file-wide count with each surviving
      match attributed by function (`show`, `undo`/`execute_revert`, and the shared helpers). A
      file-wide zero is **not** the target.
- [ ] **AC17** `fn render_diff(result: &DiffResult) -> String` and
      `fn render_blame(result: &BlameResult) -> String` — **no opts parameter on either**. Their
      signatures admit no `&Path`, no `BlobStore`, no `&[LogRecord]`, no closure over any of those.
      `diff <turn>` ≡ `render_diff(&view.diff(q)?)`; `blame <target>` ≡ `render_blame(&view.blame(q)?)`.
      RED before rewiring: with the adapters still reading directly, these expression contracts
      cannot hold.
- [ ] **AC18** `diff`'s lookup-failure prose is byte-identical to `diff_unknown_id.golden`
      (`agentrec: unknown turn id '<ref>' — recorded turns: t_RICH…TUR1..t_EDGE…TUR9 (8 turns)`,
      exit 1) **while the adapter computes nothing from the ledger** — the range comes from
      `TurnRangeSummary`, `fmt::short_id` truncation stays adapter-side, and the count is over the
      **unfiltered** turn vec (which is why the golden says 8 over 7 distinct ids).
- [ ] **AC19** `blame`'s two user-error arms are byte-identical with the prose adapter-side:
      `blame <file>:<n>` past EOF → stderr `agentrec: <path> has only N line(s)`, exit 1 (pinned by
      `blame_line_out_of_range.golden`); `blame <missing>:<n>` → stderr `agentrec: <path>: not found`,
      exit 1. **The not-found arm is pinned by nothing today** (`rg ': not found'
      cli/tests/integration.rs` → 0) — add a new integration assertion; it is not in `golden.rs`'s
      residual list. RED if `view::blame` returns a message string.
- [ ] **AC13 (diff half)** A `DiffQuery` cursor replayed after a `purge --log-duplicates` rewrite
      returns `stale_cursor`; a cursor from a *different* `DiffQuery` (different turn or paths)
      returns `QueryMismatch` rather than silently paging the wrong query.
- [ ] **All 33 goldens byte-identical** at this commit (27 pre-existing + P4b-1's six —
      corrected in P4b-5; P4b-1's gate added a 6th mid-task).

## Commit

```
P4b(2/5): diff + blame into RepositoryView, adapters render-only

Adds DiffResult/FileDiff/BlameResult/DiffError/BlameError to agentrec-core::view
and reduces readcmds::diff and readcmds::blame to pure renderers over them.

diff returns an envelope, not Page<FileDiff>: the golden-pinned header
`turn <id> · <tool> · N files` has no carrier on a bare page, and a fileless
turn's empty page would make it unproducible (design R20).

Typed errors carry the data their prose needs and no prose: DiffError::Lookup
carries the ledger range diff_unknown_id.golden requires, BlameError carries the
line count blame_line_out_of_range.golden requires.

show and undo keep their direct reads by design — the shared helpers stay in
readcmds.rs and view::diff resolves blobs independently.
```

## Notes

- **`blame_line`'s heuristic must move verbatim.** Known v1 limitation (a verbatim-duplicated line
  cannot be told from its duplicate) is documented behavior, not a bug to fix here.
- **Edge cases:** fileless turn; zero-turn repo; log with only epoch records; duplicated turn id
  (collapse) vs distinct turns sharing an id (ambiguous); `line_no == 0` (unreachable from the CLI
  since `parse_target` requires a positive integer, but `LineOutOfRange` covers it for future MCP
  callers); a `create` op's `None` before-hash is legitimately-empty text, **never** unresolvable —
  collapsing that would deny credit to every file-creating turn.
- **Resource shape (accepted, design R16):** `Page<FileDiff>` pre-resolves every entry's content, so
  a pure renderer holds a whole turn's blobs at once where `print_entry` streamed one pair at a time.
  Bounded by the store's 10 MiB per-blob cap × entry count. Accepted as the price of the signature
  constraint; the escape hatch if it ever bites is the adapter paging `DiffQuery.limit` internally.
